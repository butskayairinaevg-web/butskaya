# Ирина Буцкая — Лендинг эксперта по управлению качеством

Одностраничный сайт эксперта + набор генераторов документов по качеству (FMEA, Control Plan, PSW и др.).

Публикуется на **GitHub Pages** (ветка `main`, папка `/`).

## Структура

```
butskaya-landing/
├── index.html           ← редирект на landing/
├── landing/index.html   ← лендинг (консультации и услуги)
├── shop/index.html      ← магазин QDoc — документы по качеству (оплата через Ю-мани)
├── generators/          ← онлайн-генераторы документов качества (бесплатные инструменты)
├── robots.txt
├── sitemap.xml
└── README.md
```

## Магазин QDoc

Каталог документов по качеству (FMEA, Control Plan, PSW, SPC, MSA, APQP, PPAP, 7 QC Tools). Доступ ко всем PDF — 3 500 ₽ через Ю-мани.

## Публикация

1. Репозиторий → GitHub Pages (ветка `main`, папка `/`)
2. Открыть `https://<user>.github.io/<repo>/` — редирект на лендинг
3. Магазин доступен по `shop/index.html`, лендинг ссылается на него
4. Подключить свой домен (CNAME), когда решим вопрос с DNS
